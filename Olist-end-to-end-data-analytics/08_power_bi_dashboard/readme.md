# Dashboards

Built in Power BI Desktop on top of the validated, modeled tables from earlier in the project — DAX measures on top, SQL-derived tables underneath.

## 1. E-Commerce Performance Dashboard

5 pages covering customers, orders, sellers, products, and categories, all built on the star schema from `06_star_schema/ecommerce/`.

## 2. Marketing Funnel Performance Dashboard

Tracks the seller-acquisition funnel end to end: MQL → closed deal conversion, which lead origins perform best, and the revenue quality of the sellers that come out the other end.

## Getting the file

Due to GitHub's size limits, the `.pbix` file itself isn't in this repo — it's linked in `olist_dashboard_link.md` (Google Drive). Open it in Power BI Desktop to get the full interactive experience with filters and cross-highlighting.
